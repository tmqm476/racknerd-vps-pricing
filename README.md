## 购买流程与四个容易出错的细节

下单本身不难：选套餐 → 选机房和系统（Ubuntu、Debian、AlmaLinux、Rocky Linux、CentOS 等，可开工单装自定义 ISO）→ 付款 → 几分钟内邮件收到 IP 和 root 密码 → SSH 连上去就能用。支付支持**支付宝**、PayPal、主流信用卡和加密货币，国内用户扫码付款即可。全程通常不超过十分钟。

真正容易出问题的是这几处：

1. **注册时别挂代理**。下单用你常用的网络 IP 直接访问，挂梯子可能触发风控进入人工审核，反而拖慢开通。
2. **套餐之间不能原地升配**。从 1GB 换 2GB、或换机房，都需要新购或提工单迁移数据，IP 也可能变。拿不准配置就宁可选高一档。
3. **IPv6 默认不配**。洛杉矶等部分机房的套餐可免费申请 IPv6（据老用户分享最多可到 100 个），下单后开工单申请即可，具体以客服答复为准。
4. **这是非托管服务**。环境安装、防火墙、备份、SSH 加固全要自己来，VPS 一开通就是公网暴露状态，改密码、改端口这几步越早做越好。完全没有 Linux 基础的话，它对你会有上手门槛。
